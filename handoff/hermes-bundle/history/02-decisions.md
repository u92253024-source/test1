# 決定與理由

| 決定 | 理由 |
|---|---|
| 問卷具名＋不列考核聲明 | 要能分組與聯絡；聲明換取誠實作答 |
| 能力題用行為式提問 | 自評會失真：高手謙虛、新手高估 |
| 不在問卷問意願，改在邀請信設退出台階 | 被主管推薦的人被問「是否自願」會尷尬；信末一句即可 |
| 一個核心社群＋三軌 | 三軌各只有 1–2 人，獨立開會會散 |
| 第一專案選學分抵免與學程認定 | 痛點人數最多、跨兩單位、法規明確有標準答案、已有人握有資料 |
| 資安併入提示詞課 | 問卷顯示無人想上資安課，但多數人不清楚界線；用高票主題夾帶 |
| 提示詞排第一、試算表第二、NotebookLM 第三 | 依問卷票數，且形成遞進：先會問、再會整理、才能建 |
| 唯一的技術主力給舞台，不當學生 | 他有能力但對社群需求低；讓他當技術指導才留得住 |
| 示範用 ThinkFirst，單機示範 | 它是 Claude Code skill，公務桌機不必安裝 |
| 簡報做 pptx＋HTML 兩份 | pptx 為主，HTML 離線單檔為備援（Wi-Fi 風險） |
| Gemini 版讓使用者填自己的金鑰 | 金鑰寫進網頁任何人都看得到；免費方案就夠練習 |
| 問卷回覆原檔與逐人分析不進 GitHub | 小樣本可反推個人，違反「不提供主管」承諾 |

## 問卷整體結論（8 份，已去識別化的整體層級）
- 底子比預期好：熟練以上約六成，無人完全沒接觸 AI，無人沒聽過 NotebookLM。
- 唯一「進階」者動機低（有能力、沒需求）。
- 多數人選「先觀望」，但多數已自費訂閱 AI → 不是冷漠，是不知道自己能扮演什麼角色。
- 查證意識好，個資界線感弱。
- 痛點群聚：學分抵免與學程認定（3 人跨 2 單位）、招生報名作業（2 人同單位）。
- 現成資料來源少：多數人手上沒有整理好的文件，資料整理是建置詢答服務的最大成本。
